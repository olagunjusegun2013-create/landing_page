# Lumen House Photography Studio

A responsive photography studio website built with HTML, CSS, and vanilla JavaScript.

## Run the project
Open `index.html` in a modern web browser. No package installation or build process is required.

## Pages
- `index.html` — animated lens hero, studio introduction, photo sessions, contact, and footer
- `work.html` — selected photography gallery with click-to-preview images
- `catalog.html` — photography samples with category filters and click-to-preview images
